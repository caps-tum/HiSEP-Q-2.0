Revision note
- This QSG program now exercises the `QSG.MEASURE` path at every LMUL point: `mf2`, `m1`, `m2`, `m4`, and `m8`.
- Every `QSG.MEASURE` is wrapped by two scalar marker instructions:
  - a pre-marker `addi x6, x0, imm`
  - a post-marker `addi x7, x0, imm`
- The pre-marker is used as the `rs2` source of the following `QSG.MEASURE`, so its 32-bit value is visible on `elem2`.
- The post-marker is used to confirm halt-resume behavior: it must not retire until the measure handshake completes and `measure_done` releases the machine.
- A guard `nop` (`00000013`) is still kept immediately after each `vsetvli`, because this implementation may reject a `vle8.v` that follows `vsetvli` too closely.

Expected behavior
- `elem1` follows the loaded 8-bit source vector for each LMUL block.
- `elem2` equals the 32-bit pre-marker from `x6`, so the five streams should carry:
  - `mf2  -> 00000081`
  - `m1   -> 00000082`
  - `m2   -> 00000083`
  - `m4   -> 00000084`
  - `m8   -> 00000085`
- `qvsg_meas` should assert for each `QSG.MEASURE`.
- `measure_issued_done` should pulse after each stream has drained.
- The corresponding post-marker in `x7` should only appear after `measure_done` has been returned by the testbench.
