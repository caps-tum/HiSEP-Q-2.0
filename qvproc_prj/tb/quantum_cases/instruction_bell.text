Bell-state preparation demo with measure halt-resume

Program intent
- `AVL=8`, `SEW=e8`, `LMUL=mf2`
- control indices: `[0, 2, 4, 6, 8, 10, 12, 14]`
- target indices: `[1, 3, 5, 7, 9, 11, 13, 15]`
- scalar tag for the H-like and MEASURE stages: `x7 = 0x55`
- scalar tag for the post-measure resume marker: `x6 = 0x66`
- this demo relies on the current `qvproc_top` measure flow:
  - `qvsg_meas` asserts when the MEASURE gate is issued
  - fetch/offload are blocked while the measurement is in progress
  - the tb waits 50 cycles, then asserts `measure_done`
  - the first `QV.SINGLE` after `measure_done` proves that execution resumes

Instruction flow
1. `addi x6, x0, 0x66`
   - preload a simple scalar tag for the post-measure resume marker

2. `addi x7, x0, 0x55`
   - preload a scalar tag for the H-like and MEASURE single-gate stages

3. `addi x5, x0, 8`
   - set `AVL=8`

4. `vsetvli x0, x5, e8, mf2`
   - configure the vector unit for an 8-element `e8,mf2` program
   - this matches the current top-level MEASURE event budget logic, so the
     `QSG.MEASURE` stream can drain and pulse `measure_issued_done`

5. `nop`
   - guard cycle for `vtype/vl` settling

6. `lui a0, 0x1`
   - base pointer `a0 = 0x1000`

7. `vle8.v v1, (a0)`
   - load control indices `[0, 2, 4, 6, 8, 10, 12, 14]`

8. `addi a1, a0, 8`
   - point to the target-index block at `0x1008`

9. `vle8.v v2, (a1)`
   - load target indices `[1, 3, 5, 7, 9, 11, 13, 15]`

10. `QV.SINGLE vd=v3, vs1=v1, rs2=x7`
    - H stage for the control group
    - fixed `GateID=7'h64`

11. `QV.PAIR vd=v3, vs1=v1, vs2=v2`
    - CNOT stage with `v1` as control and `v2` as target
    - fixed `GateID=7'h66`

12. `QV.SINGLE(MEASURE) vd=v3, vs1=v1, rs2=x7`
    - reserved `GateID=7'h68`
    - should assert `qvsg_meas`, then pulse `measure_issued_done`
    - the tb waits 50 cycles before asserting `measure_done`

13. `QV.SINGLE vd=v6, vs1=v2, rs2=x6`
    - post-measure resume marker
    - this uses a second legal placeholder `GateID=7'h78`
    - this is not part of the pure Bell-state algorithm; it is only here to
      prove that execution resumes immediately after `measure_done`

14. `jal x0, 0`
    - self-loop after the resume marker
    - no extra padding or replay loop is needed now that the halt-resume
      boundary is handled by the current top-level logic

Data layout
- `0x1000`: first four control indices `0x06040200`
- `0x1004`: second four control indices `0x0E0C0A08`
- `0x1008`: first four target indices `0x07050301`
- `0x100C`: second four target indices `0x0F0D0B09`
