LEGACY OP-V FIXTURE NOTES

These notes describe the matching split `.mem` image used by legacy trace benches.
Words, `vd`/`vm` fields, and mnemonic spellings here are not canonical custom-0
assembly. Use `docs/HiSEPQ_ISA_spec.md` for the current ISA and `demo/*.mem` for
the maintained unified stimuli.

Revision note
- The current `instruction_qpr.mem` inserts a guard `nop` (`00000013`) immediately after each `vsetvli`.
- Reason: this implementation may reject a following `vle8.v` if `vtype/vl` has not become visible yet.
- New guard-`nop` lines are 3, 10, 18, 26, and 35.
- For each inserted `nop`, all subsequent line numbers in the original walkthrough shift down by 1.
- Each guard `nop` decodes to `addi x0, x0, 0` and is expected to leave architectural state unchanged while giving the vector configuration path one extra cycle to settle.
- The `vsetvli` encodings were also corrected from `4C..F057` to `0C..F057`.
- Reason: the previous words set an extra high bit in the `vtypei` immediate, so the decoder saw `rs2_o.r.xval[31:8] != 0` and marked the configuration invalid.
